## Description
A Python Flask web app that scans a user's resume and matches it with predefined job listings based on skills using cosine similarity.  

## Features
- Paste your resume text to find matching jobs.
- Calculates similarity score for each job.
- Sorted job recommendations displayed on the web page.
- Simple HTML/CSS frontend with Python backend.

## Technologies
- Python, Flask
- NumPy, scikit-learn
- HTML, CSS
